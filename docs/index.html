How it works

People who liked this also liked…

A transparent engine built from co-occurrence across domains. No black box: every score comes from counting real users.

Start from your likes

Everything the user liked in the source domain, such as Books.

Find similar people

Other users who liked the same items.

Count across domains

What those users liked in the target domain, lightly damped by popularity.

Explain the pick

Each recommendation names the item that led to it and how many users back it.

Results

Tested on real users

Leave-one-user-out: each test user's own ratings are hidden, then their top 10 is checked against what they really liked. 300 users per direction, compared with recommending the most popular items.

LLAMARECPopularity
+45%

Higher hit rate than recommending popular items, measured on Books → Movies & TV.

About 1 user in 4 finds something they genuinely liked in their top 10, using only their ratings in the other domain.

Reproduce: python app.py evaluate-engine --k 10 --n 300

Get started

Run it on your machine

Python 3.10+. The data comes from Amazon Reviews 2023.

# install
git clone https://github.com/ThanigaiSingaravelan/llamarec-crossdomain.git
cd llamarec-crossdomain
python -m venv venv
venv\Scripts\activate   # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt

# build the data once, then run
python app.py preprocess all
python app.py serve      # → http://127.0.0.1:5000
JSON API
GET/api/healthStatus and domains
GET/api/usersList or sample users
GET/api/items/searchSearch titles
POST/api/recommendPicks for a user or a list of liked items
GET/api/evaluateRun the evaluation
